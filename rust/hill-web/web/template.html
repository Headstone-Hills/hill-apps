Hill Apps

Four small music tools, rebuilt in Rust and compiled to WebAssembly. The same code runs on the RG35XXSP and R36S handhelds.

Your samples

Every app has built-in sounds. To use your own, add .wav files or a whole folder. They stay on this device (kept in your browser's storage) and appear in each app's sound browser.

Keyboard: arrows = D-pad, A B X Y, Q W = L1 R1, E R = L2 R2, O = Select, P = Start, U = FN. FN + SELECT shows every control for the app.
